一、T0级阵容搭配（吃鸡率最高）
============================================================

1.1 尼菈 + 辅助（琴女/风女）
评级：T0
强势原因：
- 尼菈在斗魂竞技场中加成非常高，护盾后期非常厚
- 配合琴女、风女等给盾的辅助根本死不掉
- 尼菈后期伤害打谁都很高，很难遇到打不动的坦克
打法：
- 辅助全程跟尼菈，提供护盾和治疗
- 尼菈进场输出，辅助在后方保护
- 利用尼菈的护盾抵挡爆发，持续输出

1.2 狗熊 + 乌鸦（沃利贝尔 + 斯维因）
评级：T0
强势原因：
- 狗熊前排抗伤+控制，乌鸦后排持续输出+吸血
- 双坦度阵容，很难被秒
- 乌鸦大招持续AOE+吸血，狗熊大招进场控制
打法：
- 狗熊先手上场控制，乌鸦跟上大招
- 利用乌鸦的吸血和狗熊的回复持续作战
- 缩圈后双坦优势明显

1.3 龙女 + 任意辅助/坦克
评级：T0（60%吃鸡率隐藏答案）
强势原因：
- 龙女后期随便一发普攻5%最大生命值伤害
- 保证坦度前提下攻速流，数值爆炸
- 大龙能量海克斯拿到直接质变
核心海克斯：大龙能量（唯一必选）
出装：黄昏界弓 + 棱彩装备 + 坦度装
打法：
- 前期苟住，利用海克斯叠加属性
- 后期变龙后进场，普攻秒杀脆皮
- 配合辅助提供护盾和治疗

1.4 猫咪 + 任意强势carry
评级：T0（3.0版本真神，60%吃鸡率登顶）
强势原因：
- 猫咪附着队友，自身极难被击杀
- 提供治疗、护盾、增益，大幅提升carry生存和输出
- 诅咒海克斯十分适配，多个诅咒叠加效率高
核心海克斯：诅咒海克斯（除双抗外几乎都能用到，可升级）、灵魂连接、升级
出装：救赎、坩埚（优先级更高）、坦克辅助装
打法：
- 全程附着在carry身上
- 提供治疗和护盾，利用诅咒海克斯叠加效果
- 关键时刻大招控制+治疗

1.5 卑尔维斯 + 坦克/辅助
评级：T0（后期唯一真神）
强势原因：
- 卑尔维斯后期攻速成长+真伤，无人能挡
- 配合前排坦克提供输出环境
核心海克斯：大龙能量
出装：攻速流，黄昏界弓，棱彩装备
打法：
- 前期苟住发育，叠加攻速
- 后期利用真伤和高攻速秒杀一切

二、强势阵容搭配（稳定前四）
============================================================

2.1 蔚 + 爆发类（潘森/酒桶/猴子/劫）
评级：T1
强势原因：
- 蔚单点秒人，队友跟上集火
- 双爆发阵容，快速减员
打法：
- 蔚Q进场秒一人，队友集火另一人
- 或吃果后2打1
不适合：坦克、拉扯类英雄

2.2 诺手 + 有控制的队友
评级：T1
强势原因：
- 诺手需要控制帮助叠血怒
- 队友控制住敌人，诺手叠满血怒后大招斩杀
推荐队友：酒桶、蔚、猴子、阿木木等有硬控的英雄
打法：
- 队友先控，诺手E拉接W平A叠血怒
- 大招真实伤害斩杀
- 利用利刃华尔兹海克斯多次叠血怒

2.3 劫 + 蔚/猴子（双刺客）
评级：T1
强势原因：
- 双刺客高爆发，快速秒人
- 灵活位移，难以反制
出装：刺客通用出装（幕刃、暗行者之爪、穿甲装）
海克斯：去质、法爆、秘术冲拳、利刃华尔兹
打法：
- 一人吸引注意力，另一人绕后秒脆皮
- 利用位移躲避技能，持续输出

2.4 酒桶 + 任意carry
评级：T1
强势原因：
- 酒桶百分比伤害+控制，可前排可输出
- 大招开团/保护，W百分比伤害打坦克
出装：AP装，大天使、时光杖、激发之匣
海克斯：山巴巴、面包和果酱、尤里卡
打法：
- 无限控制流，技能放得快层数叠得快
- 满层后无限控制CD，键盘滚起来
- 注意蓝量管理，时光大天使弥补蓝量

2.5 阿木木 + 高输出carry
评级：T1（S级，胜率53.3%）
强势原因：
- 阿木木团控+坦克，为carry提供输出环境
- 大招团控，Q技能开团
出装：水银之靴、残酷、心之钢、日炎斗篷、兰德里的苦楚
海克斯：任务：钢化你心、亵渎者、非凡邪恶
打法：
- 阿木木先手Q开团，大招控制
- carry跟上输出
- 利用心之钢叠加血量，日炎持续灼烧

2.6 巨魔 + 对抗龟猫/高护甲阵容
评级：T1.5
强势原因：
- 巨魔吸双抗，血克龟猫（动物园）组合
- 在龙龟开W快结束时吸双抗，把护甲干到负
打法：
- 针对高护甲阵容选择
- 利用大招吸双抗，配合队友击杀

三、黑科技/娱乐套路
============================================================

3.1 烬 - 天帝套路（21亿伤害）
评级：娱乐/黑科技
成型方法：
- 伪帝海克斯：急急小子踢踏舞 + 连波击锤
- 出装：无穷饥渴 + 一件魔王或龙心 + 其余装备
- 喝一瓶威能饮品和急速饮品
- 在备战席通过连波击锤疯狂打假人叠加踢踏舞
- 属性不停转化，短暂实现21亿伤害
- 停下一段时间会掉回正常属性，但也足以在回合内秒杀对面

3.2 狼人 - 无限回血套路
评级：娱乐/黑科技（可能是bug）
触发条件：
- 队友有喂呜喂呜套装
- 受到伤害后，队友给盾或加血有概率触发无限回血
- 伤害越高回血越多
- 例如泉水攻击也能触发，可硬抗泉水伤害带队友虐泉

3.3 请勿追击兔子 - 伤害爆炸套路
评级：拿到约等于吃鸡
机制：
- 请勿追击海克斯能触发兔子的被动
- 拿到后只需要绕对面跑一圈，就能看到被动三环不断被触发
- 不好定论算bug还是机制，几次版本更新一直没修复
- 拿到就是伤害爆炸

3.4 精怪魔法 + 奥恩
评级：强力套路
机制：
- 奥恩大招施加两段易碎
- 易碎可通过定身效果触发
- 拿了精怪魔法后，大招伤害敌人时短暂变形
- 变形也算定身，可触发易碎
- 配合奥恩大招可打出极高爆发

3.5 连闪电 + 穿甲
评级：强力套路
机制：
- 海克斯连闪电：对一个敌人造成伤害时，对其搭档造成40%真实伤害
- 前提是其友军在附近
- 搭配200以上固定穿甲的小斧
- 打肉时两秒内旁边的脆皮队友被电死
- 适合对抗双人组站一起的阵容

3.6 亮剑海克斯 + 破舰者
评级：强力套路
机制：
- 第四回合做出破舰者
- 触发破舰者100双抗加成，可以轻松一打二
- 配合亮剑海克斯的增伤
- 适合战士/坦克英雄

四、海克斯组合套路
============================================================

4.1 秘术冲拳战士流
海克斯：秘术冲拳、坦克引擎、重量级打击手
装备：心之钢、黄昏与黎明、裂隙制造者、巨型九头蛇、死亡之舞、霸王血铠、千变者贾修、焚天
特点：
- 秘术冲拳让普攻减CD，高频释放技能
- 坦克引擎增加坦度
- 重量级打击手让普攻造成最大生命值伤害
- 心之钢叠加血量，越打越强

4.2 混伤战士流
海克斯：歌利亚巨人
装备：海妖杀手等混伤装备
特点：
- 歌利亚巨人增加30%血量和30%适应之力
- 牺牲50%攻速换全面属性
- 适合技能型战士，不靠普攻打输出

4.3 双CD永动法师流
海克斯：极速之追求 + 无限循环往复
胜率：63.2%
特点：
- 冷却体系的版本答案
- 技能放得越多冷却转得越快
- 极速叠满160点无衰减
- 击杀还能永久减CD突破常规上限
- 团战中技能无限释放

4.4 大法师羁绊流（ARAM Mayhem）
海克斯：大法师（收集两个海克斯达成）
效果：释放一个技能时返还另一个技能的CD
羁绊符文：回力标、舞会女王、量子计算奏鸣曲、神圣干预、火狐自我毁灭、冰霜幽灵、神龙烈焰
特点：
- 双技能CD返还，高频释放
- 适合技能型法师

4.5 暴击飞弹流（ARAM Mayhem）
海克斯：234羁绊（连波击锤、魔法飞弹、暴击飞弹）
效果：点亮三个海克斯触发羁绊
特点：
- 魔法飞弹+暴击飞弹，技能命中后发射真伤导弹
- 连波击锤增加技能频率
- 适合长手法师

4.6 台风双响炮流（ARAM Mayhem）
海克斯：台风双响炮、下雪日234
效果：雪球获得技能急速并且增加伤害
特点：
- 雪球（标记/冲刺）CD更短，伤害更高
- 适合需要开团/追击的英雄

五、按英雄类型的阵容搭配原则
============================================================

5.1 双战士/坦克
优势：高坦度，持续作战，缩圈后优势大
劣势：爆发不足，可能被风筝
推荐组合：诺手+酒桶、盖伦+阿木木、狗熊+乌鸦
核心海克斯：歌利亚巨人、秘术冲拳、渴血、战争交响乐

5.2 战士+刺客
优势：战士前排抗伤，刺客后排切脆皮
劣势：刺客容易被秒，需要配合
推荐组合：蔚+劫、猴子+泰隆、诺手+卡兹克
核心海克斯：去质、法爆、利刃华尔兹

5.3 双刺客
优势：极高爆发，快速减员，灵活位移
劣势：坦度低，被控制后容易被秒
推荐组合：劫+蔚、劫+猴子、泰隆+卡兹克
核心海克斯：去质、法爆、秘术冲拳、Tap Dancer
注意：需要高操作，不适合新手

5.4 法师+坦克/辅助
优势：法师后排输出，坦克前排抗伤，辅助保护
劣势：法师容易被刺客切
推荐组合：酒桶+阿木木、吸血鬼+猫咪、辛德拉+风女
核心海克斯：法爆、尤里卡、加速法术

5.5 射手+辅助
优势：射手后期输出高，辅助保护
劣势：前期弱，需要发育时间
推荐组合：卢锡安+猫咪、飞机+风女、尼菈+琴女
核心海克斯：灵巧、台风、暴击流相关
注意：斗魂竞技场节奏快，纯射手发育时间有限

5.6 真神carry+猫咪
优势：猫咪全程附着，提供治疗/护盾/增益，carry输出环境极佳
劣势：猫咪自身无输出，全靠carry
推荐组合：龙女+猫咪、卑尔维斯+猫咪、尼菈+猫咪、卢锡安+猫咪
核心海克斯（猫咪）：诅咒海克斯、灵魂连接、升级
核心海克斯（carry）：根据英雄选择

六、阵容克制关系
============================================================

6.1 克制关系速查
- 高护甲坦克阵容 → 被巨魔/百分比伤害克制
- 双刺客爆发阵容 → 被高坦度+控制克制
- 持续输出阵容 → 被高爆发秒人克制
- 回血阵容 → 被重伤装备克制
- 护盾阵容 → 被真伤/百分比伤害克制

6.2 针对出装
- 对面回血多 → 凡性的提醒、莫雷洛秘典（重伤）
- 对面护甲高 → 塞尔维达的怨恨（大穿甲）、多米尼克领主的致意
- 对面魔抗高 → 虚空之杖、法穿棒
- 对面暴击多 → 兰顿之兆、冰霜之心
- 对面AP多 → 女妖面纱、星夜斗篷、自然之力

6.3 针对海克斯
- 对面高回血 → 选择减疗/重伤类海克斯
- 对面高护甲 → 选择穿透类海克斯（穿针引线）
- 对面高爆发 → 选择保命类海克斯（套娃、黎明使者的决心）
- 对面控制多 → 选择免控类海克斯（终极不可阻挡、Can't Touch This）

七、通用阵容策略
============================================================

7.1 前期策略（1-4回合）
- 选择稳定强力的第一个银色海克斯
- 优先出基础装备，保证战斗力
- 观察对手阵容，针对性出装
- 第5回合是高回报回合，尽量赢下（回血+重随点）

7.2 中期策略（5-8回合）
- 核心装备成型，海克斯选择确定玩法方向
- 第9回合高回报，关键回合
- 开始针对剩余对手调整装备
- 棱彩装备选择决定后期上限

7.3 后期策略（9回合+）
- 装备全成型，海克斯全到位
- 针对最后几个对手微调装备
- 第13回合高回报，最后关键回合
- 缩圈后近战/坦克优势明显
- 注意火圈伤害，合理利用地形

7.4 经济分配原则
- 每回合杀人350金币，尽量拿击杀
- 优先核心装备，再考虑属性加成
- 随机装备适合适配度高的英雄，省钱
- 棱彩装备4000金，拿到心仪神器物超所值
- 属性加成750金，中后期受益明显

7.5 海克斯选择原则
- 第一个银色海克斯决定前期节奏，不能随便选
- 金色可以凑活，银色和棱彩不能乱选
- 优先选择与英雄机制契合的海克斯
- 棱彩优先选改变玩法的质变级强化
- 考虑与队友海克斯的联动效果
